# Чат-бот Университета «Синергия»

Информационный чат-бот для абитуриентов и обучающихся Университета «Синергия».
Распознаёт тему вопроса по ключевым словам и выдаёт подготовленный ответ:
о программах, стоимости, формах обучения, приёмной комиссии, документах,
образовательном кредите, общежитии, поступлении иностранных граждан и др.

Проект выполнен в рамках производственной практики (Кейс-задача № 3).

## Возможности

- Обработка вопросов на русском языке (лемматизация через pymorphy3).
- 18 содержательных категорий вопросов + распознавание непонятого запроса.
- Два тона ответов: академический и дружелюбный (переключаются в настройках).
- Три уровня логики распознавания (по нарастанию сложности):
  - **Уровень 1** — лемматизация + взвешенное пересечение ключевых слов;
  - **Уровень 2** — + spaCy, словарь синонимов, приоритет намерения, память диалога;
  - **Уровень 3** — каскад: уровень 2, затем семантическое сходство
    (векторное на `ru_core_news_lg` либо TF-IDF) для перефразировок.

Реализованы все три уровня. Уровень по умолчанию задаётся в `bot.py`.

## Требования

- Python 3.12 или новее (проект разрабатывался под 3.14).
- Библиотеки из `requirements.txt`.

## Установка

```bash
# 1. Создать и активировать виртуальное окружение
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux / macOS

# 2. Установить зависимости (вместе с моделью ru_core_news_lg, около 500 МБ)
pip install -r requirements.txt

# 3. Загрузить данные NLTK (стоп-слова)
python -c "import nltk; nltk.download('stopwords')"
```

## Запуск

```bash
python bot.py
```

Настройки тона и уровня задаются в начале файла `bot.py`:

```python
TONE = "academic"   # "academic" или "friendly"
LEVEL = 3           # уровень логики (1, 2 или 3)
SEMANTIC_METHOD = "vectors"  # для уровня 3: "vectors" или "tfidf"
```

Для выхода из диалога введите «выход», «пока» или нажмите Ctrl+C.

### В Telegram

Бот в Telegram использует то же ядро и те же настройки из `bot.py`.

```bash
# 1. Создать бота у @BotFather и получить токен
# 2. Задать токен в переменной окружения BOT_TOKEN
set BOT_TOKEN=123456:ABC...          # Windows (cmd)
# export BOT_TOKEN=123456:ABC...     # Linux / macOS
# 3. Через прокси (необязательно), например SOCKS5:
# export BOT_PROXY=socks5://user:pass@host:1080
# 4. Запустить
python telegram_bot.py
```

Если задана переменная `BOT_PROXY`, бот подключается к Telegram через
указанный прокси (SOCKS5 или HTTP); без неё — напрямую. Журнал подключения
и сетевых ошибок выводится в консоль.

Память диалога у каждого чата своя. Бот отвечает, пока запущена
программа; модель `ru_core_news_lg` занимает около 1 ГБ оперативной памяти.

## Тесты

Запуск всех тестов:

```bash
pytest
```

Ожидается `passed` в итоговой строке. Подробная инструкция (что проверяет каждый файл, как сохранить вывод, как проверить векторную ветвь) — в файле `TESTING.md`.

## Источник данных

Содержание ответов основано на сайте synergy.ru по состоянию на 05.05.2026.
Этот сайт ведёт рекламное агентство ООО «Синергия Диджитал»; официальный
сайт Университета «Синергия» — synergyuniversity.ru. Стоимость обучения,
адреса и контакты следует сверять с официальным сайтом.

Набор данных о стоимости обучения в `data/prices` составлен по приказам
Университета о стоимости на 2025/2026 учебный год; состав и правила —
в `data/prices/README.md`. Бот этот набор пока не загружает.
