# Стоимость обучения на 2025/2026 учебный год

Набор данных для детализации ответа о стоимости обучения: по одному файлу
на каждый приказ Университета «Синергия» о стоимости платных образовательных
услуг для зачисленных на первый курс в 2025/2026 учебном году (для школы —
для зачисленных в 2025/2026 учебном году). Набор загружает модуль
`chatbot/prices.py`: если в вопросе названо направление подготовки или
программа, бот перечисляет найденные программы с ценами.

## Структура файла

```json
{
  "meta": {
    "source_order": "Приказ № 173/2001098 от 01.08.2025",
    "level": "бакалавриат",
    "applies_to": "зачисленных на первый курс в 2025/2026 учебном году",
    "academic_year": "2025/2026",
    "currency": "RUB",
    "period": "год"
  },
  "items": [
    {
      "direction": "Прикладная информатика",
      "program": "Прикладная информатика в экономике",
      "form": "очная",
      "price_year": 330000,
      "price_total": 1320000
    }
  ]
}
```

- `meta` — сведения о приказе: уровень образования, кому адресованы цены
  (в форме для фразы «Цены для …»), учебный год, валюта, период цены.
- `direction` — направление подготовки или специальность, `program` —
  образовательная программа. Если в приказе вместо названия программы стоит
  прочерк или «нет», `program` равно `null`, и в ответе называется направление.
- `price_year` — стоимость за год, `price_total` — за весь период обучения.
  У школы полной стоимости нет: цена указана за год обучения в классе
  (`price_total` равно `null`).
- У программ среднего профессионального образования цены хранятся по базам
  приёма — после 9 и после 11 класса:

  ```json
  "by_base": {
    "9":  { "price_year": 240000, "price_total": 960000 },
    "11": { "price_year": 240000, "price_total": 720000 }
  }
  ```

  Если приказ предусматривает приём на программу только после 9 класса,
  в `by_base` одна база (6 программ из 23).

## Что включено и что нет

- В каждый файл включена выборка программ, а не все программы приказа.
- Для каждой программы взята базовая стоимость. Варианты с особыми условиями
  не включены: «с учётом УММ» (среднее профессиональное образование),
  «с гарантированным трудоустройством» (бакалавриат), «для выпускников
  Университета» (аспирантура), строки в долларах США.
- Школа: заочная форма обучения с прикреплением к школе.
- Среднее профессиональное образование: программы классического обучения,
  очная форма.
- Приказы о стоимости для переведённых на второй и последующие курсы в набор
  не входят.

## Отличия от текста приказов

Все суммы сверены с текстом приказов построчно. Названия приведены
к читаемому виду:

- «ИСиТ» → «Информационные системы и технологии»,
  «МОиАИС» → «Математическое обеспечение и администрирование информационных
  систем» (бакалавриат);
- исправлены опечатки: «игоровой» → «игровой» (бакалавриат; в том же приказе
  встречается верное написание), «драмматического» → «драматического»
  (специалитет), «стоматолгический» → «стоматологический» (среднее
  профессиональное образование);
- в специалитете у второй программы «Врач-лечебник» добавлено уточнение
  «(программа сокращённого классического обучения)» — так она обозначена
  в приказе.
